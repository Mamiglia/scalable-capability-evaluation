# small-judge — stable commands
#
# PURPOSE
# Two repositories measure different things about the same GPQA transcripts.
# gpqa_tfa measures whether a model-level transcript property is associated with
# held-out GPQA accuracy. This repository measures whether an LLM judge follows that same
# property when choosing between two transcripts. A property the judge follows
# that does not track accuracy is a judge bias, and the bias map is the output
# that names them.
#
# Read the RUN LOG at the end for what has actually been run and what it found.

# --------------------------------------------------------------- corrections
# Recorded because each was wrong in an earlier version of this analysis.
#
# The R-hat checker never worked. model.py recorded the reference column of
# judge_condition_effects, which is identically zero, so its R-hat is NaN and
# hibayes' `np.all(r_hat < threshold)` was false on every run regardless of
# convergence. Fixed by recording only the free contrasts: 251 parameters with
# 4 NaN became 247 with none, and the checker passes.
#
# `identified` was always true for condition contrasts. It looked up
# "transcript_condition", but hibayes stores "transcript_condition_index".
#
# NaN in a predictor kills the sampler silently. Process features are NaN on
# answer-only transcripts (771 rows, 0.84%). hibayes passes them into the design
# matrix, every gradient becomes NaN, and the fit still "completes" and emits
# coefficients. Complete cases are now taken for every fit, uniformly, so the
# families stay comparable.
#
# Two feature pairs are exact linear identities and cannot share a block:
# proc_conclusion_tail_frac = 1 - proc_first_conclusion_position, and
# repetition = 1 - ttr. gpqa_tfa never saw this because it fits one feature at
# a time. Dropped from joint blocks, kept in marginal fits.
#
# length_structure is one construct measured nine ways: condition number 27.5
# with n_chars and n_words correlated at 0.992. Its joint coefficients were
# meaningless (log_n_words +0.92 against n_words -0.71). The block is now
# refitted on the 4 components spanning 90% of its variance, following
# gpqa_tfa/src/stats/factor_check.py. Condition number after: 1.000.
#
# A credible interval is not a multiplicity-controlled claim. The judge analysis
# now reports Benjamini-Hochberg values within family and globally, and it uses
# the global value for verdicts. The capability table applies one correction
# across all 138 hand-built features (`method == hand-built`).
#
# `process` was reported as failing convergence three times before the numbers
# were checked. Its worst R-hat is 1.01 against a strict `< 1.01` threshold and
# its lowest effective sample size is 889 against 1000, across 891 parameters.
# It was never broken.
#
# The truncation prediction in transcript_features.py was wrong. The process
# NaN gate was documented as firing far more often under truncation; measured,
# it fires on 0.8% of rows and is flat across truncation levels.
#
# FIXED 2026-08-11. The between-part factor loadings written before that date
