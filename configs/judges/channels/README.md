Pairwise channel conditions: the Kimi-K2-Thinking reasoning-shown baseline judging part of each
transcript. Channels are reasoning, text (assistant prose), calls (tool calls) and outputs (tool
outputs); tools names calls and outputs together. The seven conditions: drop-reasoning, drop-tools,
drop-outputs, only-reasoning, only-text, only-calls, only-outputs. The full transcript is the baseline
itself. Logs land in logs/judge_channels-<only|drop>-<c>/<domain>/<semester>/kimi-k2-thinking/<hash>.
