    \item \textbf{Judged items.} From the saturated set, we draw a fixed random sample of up to 25 items from each quartile of item difficulty $b_i$, for a maximum of 100 items. For section and channel removal with pairwise judging (Section \ref{sec:results-source}), we used a fixed 40-item subset (10 per quartile). The same candidate items are used for every model and protocol; a model contributes a transcript for an item only when it answers that item correctly.
